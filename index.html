Command modes

Goal: know which mode you are in from the prompt, and how to move between modes. Each mode has its own color in this guide, and each one sits deeper than the one before.

  1. User EXEC mode Switch>

    • Default mode when you connect to a Cisco device
    • Limited set of commands available

  2. Privileged EXEC mode Switch#

    Enter with enable from User EXEC mode.

    • Access to advanced commands and configuration options

  3. Global configuration mode Switch(config)#

    Enter with configure terminal from Privileged EXEC mode.

    • Configure the device's overall settings and parameters

  4. Interface configuration mode Switch(config-if)#

    Enter with interface plus the interface identifier, from Global configuration mode.

    • Configure a specific interface on the device

  5. Line configuration mode Switch(config-line)#

    Enter with line plus the line identifier, from Global configuration mode.

    • Configure a specific line, such as the console or VTY lines

Moving through the modes

Switch> enable
Switch# configure terminal
Switch(config)# interface vlan 1
Switch(config-if)# exit
Switch(config)# line console 0
Switch(config-line)# end
Switch# disable
Switch>
Remember

exit goes back one level. end (or Ctrl+Z) jumps straight back to Privileged EXEC mode.

Configure passwords

Goal: protect Privileged EXEC mode and the console and remote-access lines.

enable password <password>
Sets the password for Privileged EXEC mode
Stored as plain text unless service password-encryption is on
enable secret <password>
Sets the password for Privileged EXEC mode, stored as a hash (more secure)
If both are set, enable secret is the one that is used

Privileged EXEC password

Switch(config)# enable password mypassword
Switch(config)# enable secret mysecretpassword

Console line password

S1(config)# line console 0
S1(config-line)# password <password>
S1(config-line)# login

Remote (VTY) lines, same pattern

S1(config)# line vty 0 15
S1(config-line)# password <password>
S1(config-line)# login
Easy to forget

A line password does nothing until you also enter login, which tells the line to ask for it.

Encrypt passwords

service password-encryption
Scrambles all plain-text passwords in the configuration file
Switch(config)# service password-encryption
Remember

This encryption is weak. It only keeps someone from reading a password over your shoulder. enable secret is the stronger protection.

Banner messages

banner motd #message#
Displays a message of the day when someone connects
The # is a delimiter. It marks where the message starts and ends, so the message itself cannot contain that character.
Switch(config)# banner motd #Authorized access only#

Configure an IP address

Goal: give the switch an address so you can manage it remotely, using the management VLAN interface.

SW1(config)# interface vlan 1
SW1(config-if)# ip address 192.168.1.1 255.255.255.0
SW1(config-if)# no shutdown
  1. Enter the interface: interface vlan 1
  2. Set the address and subnet mask: ip address
  3. Turn the interface on: no shutdown

Check yourself

Answer out loud first, then open the question.

Which prompt shows you are in Privileged EXEC mode?

Switch#

How do you get from User EXEC mode to Global configuration mode?

Type enable, then configure terminal.

What is the difference between enable password and enable secret?

enable secret is stored as a hash and is used if both are set. enable password is stored as plain text.

You set a console password but the switch never asks for it. What did you forget?

The login command on the line.

What is the difference between exit and end?

exit goes back one level. end goes straight to Privileged EXEC mode.

Which commands give VLAN 1 an address and turn it on?

interface vlan 1, then ip address 192.168.1.1 255.255.255.0, then no shutdown.

How do you keep your configuration after a restart?

copy running-config startup-config
